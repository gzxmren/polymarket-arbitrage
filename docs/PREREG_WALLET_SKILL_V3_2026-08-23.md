## 1. 动手前三问

**Q1 服务哪条需求?** 项目唯一目的是赚钱。方向三问的是:
**能不能从历史战绩里挑出一批钱包,他们接下来的下注仍然赚钱。**
这是"信息越独家越可能赚"这条路上最直接的一个检验。

**Q2 不做会怎样?** 08-19 判过一次 🔴,但那次的尺子看不见能赚钱的量级(§2)。
不重测 = 一个可能成立的方向被一个无效的检验永久关闭。

**Q3 怎么验证?** 见 §6 功效闸 + §7 红线 + §8 双臂判读规则,全部先写死。

## 2. 为什么 V2(2026-08-19)那次判决作废

那次主判 +3.6782pp,未越置换零分布 p95 = **+4.1646pp**,判 🔴。
**但赚钱只需要约 1pp** ⇒ 那把尺子的最小可分辨效果是所需的 4 倍。

⭐**而且不是阈值定错**:原红线 +0.5pp 被实测出 62% 的随机组能越过(必须抬高才有效)
⇒ **那套「钱包组合聚合」的设计,不存在一个既有效又有用的红线** —— 问题在方差,不在阈值。
⇒ 「未越红线」在那个设计下**不构成证伪**,只说明看不见。

## 3. ⭐定义检查(定义 vs 后果)

- **要测的东西,一句话**:一条在结果揭晓前就定好的挑人规则,照它下注,**扣掉成本后仍然赚**。
- **卡门槛的变量**:被挑中的钱包在**它们没参与过排名的那段时间**里,每一美元实际赚了多少(pp)。
- **是定义本身吗?** 是。
  拿掉"样本外" → 是拟合;拿掉"扣成本后为正" → 只是个规律不是钱。
  而拿掉"排名稳定""相关显著""校准偏差"这些,只留"样本外、扣成本、净赚" ⇒ **它仍然是 edge**。
  ⇒ 那些都是旁证,只有这一个是定义。

⚠️ **一处口径更正(V2 未写清)**:本单的 edge = `win − 成交价`,
用的是**实际成交价**,所以它**已经扣掉了入场时付出的价差**(你是主动成交方就付了)。
持有到结算无出场成本。⇒ **edge > 0 即为赚**,不需要再减一次 0.5pp。
过去"需要 1pp 才能覆盖 0.5pp 成本"的说法是重复扣减,本单更正。
⚠️ 但**平台手续费未建模**(实测部分体育盘 `feeType=sports_fees_v3`,含 taker 费与返佣),
故 §7 的绝对下限保留 **+0.5pp** 作为对未建模费用的安全边际。

## 4. 分窗(可交易口径,不是事后口径)

| | 定义 |
|---|---|
| 边界 T | **2026-08-08 00:00:00 UTC** |
| **发掘窗 D** | 结算时刻 `closed_time < T` 的市场上的全部成交 |
| **验证窗 V** | 结算时刻 `closed_time >= T` 的市场,**且下单时刻 `ts >= T`** |

⭐**V 窗要求下单也在 T 之后**:排名只能在 T 时刻形成,T 之前你不可能照它下注。
只按结算时间切、不管下单时间,会把"边界前就已下好的注"算成战果 ⇒ 那是事后口径,不可交易。

实测样本(§4 口径下,已排刷单、已过时间防火墙):
D 窗 9,834,277 笔 / 208,319 钱包;V 窗 7,723,168 笔 / 103,175 钱包;
**两窗各 ≥20 笔的钱包 15,691 个**(前 10% = 1,569 个)。

## 5. 口径(两臂**逐条相同**,只差 §8 那一个自变量)

1. 只用已结算且 `resolved_outcome` 非空的市场
2. `win = (outcome_index != resolved_outcome)` ⚠️ **与字面读法相反**,已用末价独立验证
3. **时间防火墙**:只保留 `ts <= closed_time`(硬线)。见 `DESIGN_TIME_FIREWALL_2026-08-23.md`
4. 排除刷单市场(`wash_markets.json`)
5. 钱包门槛:**两窗各 ≥ 20 笔**
6. 排名指标与因变量都用**金额加权** edge(= 一美元赚多少,与赚钱直接对应)
7. 主判决对象:按 D 窗 edge 排序的**前 10%** 钱包,在 V 窗的金额加权 edge(记作 `R_V`)

## 6. 🔴🔴 功效闸(**先跑,先判,在红线之前**)

**这是本单相对 V2 最重要的新增,针对 08-19 的真正死因。**

置换零分布:从合格钱包池里**随机**抽同样多的钱包(不看 D 窗成绩),
算它们的 `R_V`,重复 **PERM_N = 400** 次。

> **闸:若**任一臂**的置换零分布 p95 > `MDE_MAX` = +1.0pp
> ⇒ 判定「本设计对能赚钱的量级无分辨力」,直接结束,判决栏写「无判决」。**
>
> ⚠️ 两臂各有一个零分布,合并规则**取更宽的那个**(即 `max(p95_A, p95_B)`),更保守。
> (2026-08-23 review 指出:此句原本只出现在结果部分,属于预登记单未覆盖的分支。
> 本次两种取法结论相同 —— 臂 A 单独的 4.16pp 也已 > 1.0pp —— 故不影响判决,
> 但按母单铁律它本该动手前就写死,现补入 §6 并记下这次疏漏。)

⚠️ **不许在这种情况下报 FAIL** —— 那正是 08-19 犯的错:
用一把看不见的尺子量出"读数为零",然后当成"没有厚度"。
若功效闸不过,产出是**一份关于设计缺陷的报告**,不是一个关于方向三的结论。

# 结果(2026-08-23)

## 🔴 判决:**NO_VERDICT(无判决)** —— 功效闸未过

| | 臂 A(全部市场) | 臂 B(两腿配平市场) |
|---|---|---|
| 合格钱包(两窗各 ≥20 笔) | 15,691 | 13,085 |
| 主判决对象(前 10%) | 1,569 | 1,308 |
| **R_V** | +3.5252pp | +6.1829pp |
| 置换零分布 中位 | +1.4171pp | +2.3494pp |
| **置换零分布 p95** | **+4.0427pp** | **+6.0521pp** |
| 自举 95% 区间 | [−4.61, +11.17]pp,**宽 15.8pp** | [−2.06, +14.57]pp,**宽 16.6pp** |

⚠️ 上表为**修复不可复现之后**的最终数(见 §review 第 8 条);
首次跑的 p95 为 4.1600 / 5.7153 —— 差异全部来自随机量,确定性量(R_V、样本数、判决)逐字未变。

**功效闸(§6)**:零分布 p95 取两臂中更宽的 **+6.0521pp** > 门槛 +1.0pp
⇒ **本设计对能赚钱的量级无分辨力,不出判决。**

⚠️ 按 §6 明令:**不许报 FAIL/证伪**。本次产出是一份关于**设计分辨力**的报告。

## ⭐⭐ 功效闸拦下了一个具体的假信号

**臂 B 的 R_V = +6.1829pp > 它自己的零分布 p95 = +5.7153pp ⇒ 它「越过」了置换红线。**

如果没有功效闸,并且只看臂 B(或事后挑那条好看的臂),
完全可以写出「发现信号:前 10% 钱包样本外 +6.18pp,越过置换红线」这种结论。

而它是噪声:该统计量的自举区间宽 **17.3pp**,零分布中位就有 +2.35pp。
⇒ 这正是 §8「⛔不许只汇报好看的那一臂」和 §6 功效闸同时要防的东西,**两道都真的咬住了**。

## ⭐ 最重要的结论:换成逐笔口径**没有**降低噪声底

08-19 用「钱包组合聚合」,零分布 p95 = +4.1646pp。
本次用逐笔盈亏 + 时间防火墙 + 排刷单 + 更大的钱包池(15,691 vs 10,273),
零分布 p95 = **+4.1600pp(臂A)**—— **几乎逐字相同**。

⇒ **噪声不来自"观测笔数太少",来自「组合构成」**:
一组 1,569 个钱包押在哪些市场上、大仓位落在哪几笔,决定了整个统计量。
笔数从千级涨到千万级,对这个方差**没有帮助**。

⇒ 🔴 **「排名→取前 10%→算这组的总成绩」这一整族设计,对本问题是死路** ——
不是阈值问题,不是样本量问题,是**统计量本身的方差结构**问题。

## 下一步(尚未预登记,不在本单范围内)

要降方差,必须换**比较单位**:不比"这组人 vs 随机一组人"(组合构成噪声),
而比**同一个市场、同一时段内,这批人 vs 其他人**的成交价 ——
市场层面的波动在配对里被约掉。

⚠️ 这是一个**新设计**,必须另写预登记单;本单不对它做任何承诺。
