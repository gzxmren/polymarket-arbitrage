判决：那个 92 分，是自己批卷子批出来的

把"自己猜"换成"问官方要答案"，其他一切不变。十二个格子，全部翻负。项目唯一的净正候选，死了——而这是这两天最有价值的成果。

主题 Polymarket · 真值口径检验 · 选择偏差 日期 2026-07-15 系列 三部曲之三(共三篇 · 完)

00前情

一个怀疑，和一套可以验证它的答案

前两篇的故事压缩成三句话：

  • 我们找到了项目第一个通过全部预登记红线的净正候选：利用长热偏差买热门那一侧，净 +0.46%，胜率 92%。
  • 去官方补数据时发现，回测判断"市场结束没、谁赢了"用的是自己猜的土规则——看终值价收没收敛到 0 或 1。
  • 这条规则判胜负从不出错，但会静默丢掉终值没收敛的盘——而那正是"买热门"策略该亏钱的案例。

现在我们手上有 9161 个市场的官方权威答案。是时候验了。

01实验设计

只动一个变量，其他全部焊死

这个测试的全部价值，取决于一件事：自变量必须有且只有一个。否则结果出来也说明不了任何问题。

为了防止自己事后找补，我在跑数据前先写了预登记单，把判决语义钉死：

  • 代理过、官方也过（同一个 band）→ 偏差不是主因；
  • 代理过、官方全不过 → +0.46% 是偏差的产物，候选作废；
  • 代理过、官方只有别的 band 过 → 不算存活，属多重比较嫌疑。

红线一个字都没改，是从被检验对象自己的预登记单里逐字抄来的。这是这份单子可信度的唯一来源——我唯一能动的手脚就是改红线，而红线是抄的、可以 diff。

诚实声明

这份预登记单不是纯净的事前登记：写它的时候回填还在跑，我为了验证代码路径跑过一次冒烟测试，已经瞥见了部分中间数字。这一点我写进了单子的第 0 节，而不是假装没发生。

02判决

十二个格子，全部翻负

🔴 判决：edge 在权威真值下消失 → 原 +0.46% 是剔除偏差的产物

这不是擦边翻车，是塌方。而且数据完整性闸门以 100.0% 对齐（2384 个市场）通过了——所以这个结论不是脏数据造成的。

嫌疑坐实的那个数字：代理规则认 1837 个市场，官方认 9161 个。它丢掉了 80%。

03凶器

它留下的，全是赢面更大的那些

光看"丢了 80%"还不够，得看丢的和留的有什么不同。这是全市场（官方已结算的）实测：

看那个 0.905 就全明白了。价格贴到 0.9 意味着什么？意味着我们拍下这张快照的时候，胜负基本已经明朗，市场上所有人都看出来了，所以价格才会贴那么高。土规则说"价格够极端 → 算它已结束"，于是留下它们。

而被丢掉的 7351 场，入场价中位 0.745——还有悬念、还可能翻船。土规则看到这个价说"没收敛，还没结束"，全部丢掉。

后果直接写在最后一列：在"基本赢定了"的那批里，买热门赢 88%；在真正有悬念的那批里，只赢 75%。

那 88% 不是本事，是在终场哨快响的时候才下注。
04最狠的一刀

连"偏差存在"本身，都大部分是幻觉

如果说前面那些还只是"这个策略不赚钱"，那下面这个数字，是把整个方向判了死刑。

看毛利——还没扣任何成本、纯粹的市场偏差有多大：

我们以为测到的那个"教科书级长热偏差"——它本身就大部分是幻觉。真实的毛偏差只有 +0.74%，而过路费要 4.8%。

这意味着：这个 edge 从毛利层面就不够付过路费。它不是"扣完成本后薄了一点"，是"根本没有足够的肉"。

而这一刀顺带砍掉了昨天所有的后续工作——价格下限护栏、半凯利仓位、甜区精炼，全是在给一个不存在的 edge 做精装修。

05教训

真正要记住的，不是这次的结论

候选死了，这只是个结果。真正值钱的是那条规律：

绝不可用与"结果"相关的变量去筛样本。

这次的具体形态是：价格够极端 ↔ 胜负已明朗 ↔ 热门必赢。用"价格收没收敛"筛样本，等于用"结果明不明朗"筛样本——样本里就必然只剩赢定了的。

请注意这条比"别用快照价判结算"更普适：换任何一个和结果沾边的变量，都会同样炸。记这条，别只记这次的表面症状。

第二个凶手：静默

这条规则丢掉 7351 个市场，一声不吭。没有报错、没有警告、没有日志，只有一个看起来挺合理的 +0.46%。

所以修法不只是"换个真值源"，而是：任何降级、任何剔除，都必须出声计数。沉默才是真凶。

边界：快照价并不是垃圾

有个界要划准，否则会矫枉过正：

  • ❌ 用快照价推事实（"结算了吗""谁赢了"）——官方有权威答案，不该猜。
  • ✅ 用快照价当价格（edge = p − m 里的 m）——真实且不可替代。把它一起扔了，策略就没了。

一句话：快照价是"当时的价"，不是"最后的答案"。当价用合法，当答案用致命。

06止损

好消息：这个偏差只朝一个方向吹

发现这条土规则还被 engine/portfolio.py 用着、8 个回测脚本依赖它时，第一反应是"完了，几个月的结论全要重来"。

但仔细一想，不是。关键在于这个偏差的方向是单向的——它只会抬高收益。而那些脚本得出的结论是：

  • 跟鲸鱼：🔴 不赚钱（净 −2.29%，资金加权 −4% 到 −5%）
  • 跨市场套利：🔴 不成立

也就是说，它们是在被人为放水的情况下，依然是亏的。放水后仍不及格，真实水平只会更差。

偏差吹不倒本来就趴着的，只可能吹起本来站不住的。

所以：过去所有 🔴 证伪的结论，不受影响，反而更牢固；唯一有风险的，正是唯一那个 🟢 正候选——也就是今天被拆穿的这个。

07结账

这两天，到底赚了还是亏了

诚实结账。

亏的

项目唯一的净正候选没了。回到零。昨天记下的"项目首个净正候选"要划掉——记忆、文档、预登记单，全部已改成作废状态。留着比没有更危险。

赚的

  • 一套权威数据资产：十四个月历史、23 万个日价点、9161 个官方真值。这比昨天好得多的起点。
  • 一条铁律：不可用与结果相关的变量筛样本；任何剔除必须出声。
  • 过去的 🔴 结论更牢固了——它们是在放水下仍然亏的。
  • 还有最要紧的那条——
一个赔率为负的策略，在碰真钱之前被拦下了。

如果不是今天被拆穿，这个候选的下一步就是影子盘，然后是微仓实盘。它带着 −4% 的真实赔率，和一份 92% 胜率的漂亮简历。

代价是几个小时和 23 万个数据点，不是真金白银。这就是这两天最值钱的成果。

接下来

第一件事是修引擎的真值源——理由不是洁癖：那 9161 个权威真值现在是资产，但只要土规则还在，未来任何新假设的回测都会被同一个偏差污染，我们会一次次得到假阳性。改法：优先读官方真值、读不到才降级，且降级必须打印计数。

至于"接下来测什么"——不急着定。刚烧掉一个候选，而昨天的教训正是：在薄弱证据上急着往前推，做的全是无用功。

还挂着两件事：容量数据缺口（官方接口不提供逐日成交量，这是加深历史做回测前必须先解决的），以及监控的鲸鱼报告停在 06-26、快三周没有新文件。

这个项目至今没有一条被证明能赚钱的路。但它有一样东西是真的：每一条死路，都是被自己亲手、诚实地关上的。
