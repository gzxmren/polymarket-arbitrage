## 四、修复方案

### Phase 1: 数据清洗 (优先级最高)

1. **修复 whales 表** — 从 changes + positions 回填 volume/value
2. **清理过期 positions** — 归档或删除已到期的持仓
3. **刷新鲸鱼 JSON** — 重新拉取活跃鲸鱼的状态

### Phase 2: 数据管道修复

4. **统一数据库** — 废弃4个空壳数据库，只保留主库
5. **sync_changes 添加市场标题** — 从API拉取可读标题
6. **鲸鱼 JSON 增加 PnL 计算** — 基于 positions 数据

### Phase 3: 质控自动化

7. **数据质量监控** — 每日检查关键字段的空值率/过期率
8. **告警去重+自动过期** — 超过7天的告警自动标为已读
9. **套利数据过滤** — 过滤双方价格为0的误匹配
