BUG · 已修复
🔴 TimeoutError 未捕获 — Telegram 通知在网络超时时崩溃
urllib.request.urlopen(timeout=30) 的 resp.read() 在超时时直接抛出 TimeoutError， 不会包装为 URLError。原捕获子句 except (URLError, json.JSONDecodeError) 漏掉此异常， 导致每次网络超时都会让 Telegram 发送函数崩溃并冒泡到调用方。

BUG · 已修复
🔴 IncompleteRead 未捕获 — 每日价格快照反复失败
Gamma API 返回 ~736 KB chunked 响应但在 ~655 KB 处断开，引发 http.client.IncompleteRead。 原代码只捕获 URLError，导致连续 4 次失败。修复：添加 http.client.IncompleteRead， 并将 page_size 从 100 降至 50（减少单次响应体积）。
