# Polymarket 项目 Roadmap —— 从"半死原型"到"验证能否赚钱"

> 制定:2026-06-03。基于 As-Built 架构图(`docs/AS_BUILT_ARCHITECTURE_2026-06-03.md`)的真实评估。
> **核心立场:软件能做到优秀(工程问题,90% 把握);能否真赚钱取决于 edge 是否存在(未验证,赔率低)。**
> 本路线图唯一目的:用最诚实的方式,尽快回答"这套东西到底能不能扣除成本后赚钱",赚不到就明说别投。

## 铁律(贯穿全程)
1. **先验证再投**:任何策略未在回测 + 纸上交易扣除手续费/滑点/gas/冲击成本后呈正期望,一分实盘不投。
2. **代码即真相**:不信 demo 好看,信回测数字。
3. **修信号优先于扩规模**:信号失效时,所有上层都是幻觉。
4. **砍得动手**:跑不出正期望的策略老实删,不养僵尸。

## 当前评分基线(满分10):综合 ~3.3
技术架构4.5 / 代码实现3.5 / 部署架构3 / 运维质量2.5 / 数据质量5(整改后) / 赚钱edge 1。
目标:把工程维度拉到 7-8;edge 维度**用回测如实判定**(可能证实、也可能证伪)。

---

## 阶段 A —— 修"真信号"与"真数据"(没有它一切白搭)
**A1. 修 Pair-Cost 算法**:现用 outcomePrices 中间价 → yes+no 恒=1.0 → `pair_cost_arbitrage` 永远空。改用 CLOB orderbook 真实 bid/ask 价差。**这是套利策略能否被验证的前提。**
**A2. 修 PnL**:现仅抓买入方向,鲸鱼"绩效"是错的。补卖出/结算数据,算出真实已实现 PnL。**这是跟鲸鱼策略能否被验证的前提。**
**A3. 数据契约**:明确每张表的写入者/字段语义(trade-flow 鲸鱼 vs 持仓鲸鱼分清),冻结 schema。

## 阶段 B —— 回测框架 + 真实成本模型(赚钱地基的核心)★最高优先
**B1. 通用回测引擎**:历史数据回放、统一信号→持仓→结算接口、可插拔策略。
**B2. 成本模型**:Polymarket 手续费、滑点、gas、**冲击成本/容量上限**(小市场吃不下量)。
**B3. 指标**:扣成本后期望、夏普、最大回撤、胜率、容量、换手。
→ **没有 B,关于"能不能赚钱"的一切讨论都是猜。**

## 阶段 C —— 四策略按序证伪(用 B 跑)
按"最可能活→最可能死"排序,逐个给判决:
1. **跟精选鲸鱼**(我赌最有希望):先建"鲸鱼 alpha 筛选"(真实 PnL + 持续性 + 非运气),再回测跟随。
2. **跨市场套利**:验证"价差"是真套利还是结算/流动性差异造成的假象(库里只 1 行,存疑)。
3. **Pair-Cost 套利**(我赌最可能死):修好算法后看扣成本后是否还有机会;预判极罕见且被机器人秒吃。
4. 其余(动量/做市等 7 策略遗留):大概率删。
→ **每个策略产出一句话判决:正期望→进纸上交易;否→砍。**

## 阶段 D —— 工程化收尾(与 A/B/C 并行的卫生工作)
- P2 剩余:③ logging(scoped)④ gunicorn 替换开发服务器 ⑤ schema 迁移规范。
- **引擎做成受管服务 + 管道健康告警**(引擎曾死 6 周无人知;OpenClaw cron 用 admin UI 看状态)。
- Phase-3 空表:接调度产数据 or 删(取决于 C 里哪些策略活下来)。
- 清理:重复的 update-whale-states cron、data-quality-check 与 health-check 已整合。

## 阶段 E —— 纸上交易 → 执行层(仅当 C 证实有正期望)
- 先 paper trading 跑数周,验证回测正期望在"实时但不出钱"下站得住。
- 仍站得住,才启动**独立的执行层项目**(下单 API、私钥/钱包安全、实时风控、仓位上限)。
- 执行层是另一个工程,本仓库保持 read-only/advisory 直到这一步。

---

## 决策门(里程碑)
- **M1 数据干净** ✅ 已达(2026-06-03 止血)。
- **M2 信号为真**:Pair-Cost 用真实盘口、PnL 含卖出结算。(阶段 A)
- **M3 回测可信**:框架 + 成本模型就绪,能产出扣成本后期望。(阶段 B)
- **M4 正期望证实**:至少一条策略回测 + 纸上交易呈稳定正期望。(阶段 C/E)
- **只有过了 M4,才谈实盘资金。**

## 诚实赔率(下注式,持续更新)
- 软件做到优秀:~90%。
- 某策略回测扣成本后正期望:~30-40%(最可能是跟鲸鱼)。
- 该正期望在实盘仍成立:~15-25%。
→ 不是劝退,是真实赔率。挖到金子就上,挖不到就明确告诉你别投——这比赚一时幻觉值钱。

## 明天从哪开始
建议 **阶段 B(回测框架 + 成本模型)** 起步——它是判断"到底有没有金子"的唯一工具;A1/A2(修信号)可与之并行,因为回测也需要真实信号/PnL 喂入。
