# 预登记单 · 「单边采集偏移是否一视同仁」(2026-08-23)

> ⚠️ **本文写于跑任何数字之前。** 下面的判决规则先写死,看到结果后不许改。

## 1. 为什么要问这个

[[pitfall-lake-records-one-side-only]]:全湖参与者账面总盈亏 **+1.141%**,
而零和市场里所有人的平均只能是负的 ⇒ 数据只记录了单边且不对称。
偏移量级(约 1.1pp)与要找的 edge(约 1pp)**相同** ⇒ **绝对 edge 数字不可解读**。

**但如果这个偏移对所有钱包一视同仁,"谁比谁强"的相对排名仍然可用。**
这决定下一步是「可以测方向三了」还是「必须先修采集」。

## 2. 自变量与因变量

- **因变量**:两份「前 10% 钱包」名单的**重合率**。
- **自变量**:排名所用的样本 —— 全部市场 vs **采集对称的市场**。
- 一次只动这一个。其余口径(时间防火墙、刷单排除、最少下注数)两臂**逐条相同**。

## 3. 「采集对称」怎么定义(必须与钱包本事无关,否则循环)

市场级 `imbalance = |Σ(size·dir)| / Σ(size)`,dir: BUY=+1 / SELL=−1。
- 采集完整时买卖能对上 ⇒ imbalance ≈ 0
- 只采到单边 ⇒ imbalance → 1

取 **imbalance 最低的三分之一市场**作为「对称组」。
⭐这条轴只看市场的买卖是否配平,**不看任何钱包的输赢** ⇒ 不构成循环论证。

## 4. 🔴 判决规则(先写死)

| 前 10% 名单重合率 | 判决 | 后续动作 |
|---|---|---|
| **≥ 80%** | 🟢 偏移基本一视同仁 | 相对排名可用,可以用逐笔口径重测方向三 |
| 60% ~ 80% | 🟡 部分污染 | 必须做双臂对照,判读规则先写死 |
| **< 60%** | 🔴 排名被污染 | **先修采集,测什么都白测** |

**辅助指标(不单独判决,只用于归因)**:
- 两臂 per-wallet edge 的秩相关(Spearman)
- per-wallet edge 与「该钱包在不对称区的暴露比例」的相关

## 5. 口径(两臂逐条相同)

- 时间防火墙:只用 `ts <= closed_time`(硬线)
- 排除刷单市场(`wash_markets.json`,5 个)
- 只用已结算且 `resolved_outcome` 非空的市场
- `win = (outcome_index != resolved_outcome)`(⚠️ 与字面读法相反,已用末价独立验过)
- 钱包最少下注数 **20 笔**(两臂同一门槛)
- 排名指标:**金额加权** per-wallet edge(这是"一美元赚多少",与赚钱直接对应)

## 6. 本测试**不能**回答什么

- 不能回答偏移**有多大**(真实盈亏不可观测,只能看到"真实+偏移")。
- 不能回答绝对 edge 是多少 —— 那要等采集不对称本身被修好。
- 不能回答方向三成不成立 —— 它只回答「现在能不能开始测」。
- 重合率高**不等于**没有偏移,只等于**偏移没有改变排名**。

# 结果(2026-08-23,按 §4 判决)

## ⚠️ 第一版分组变量测错了东西,已作废

初版用「买卖是否配平」(`|Σsize·dir|/Σsize`)当采集对称性。实测**中位 0.9871** ——
典型市场 98.7% 单边,"对称组"门槛 0.8651 仍是 86.5% 单边 ⇒ **两臂对比度不足**。

根因:该指标的前提是错的。平台撮合时 A 买腿0、B 买腿1,**两条记录都是 BUY**,
所以"买卖不配平"是**正常现象**,不代表采集不全。
初版给出 **81.1% = 🟢**;换成正确变量后是 **75.0% = 🟡**。
⇒ 若接受了那个绿灯,后续全部会建在假前提上(CLAUDE.md:🟢 才是风险区)。

## 正确的分组变量:两条**腿**的净持仓股数配不配平

`leg_imb = |n0 − n1| / (n0 + n1)`。⭐先验对比度(必须先验,否则分组可能根本没分开):

| 分档 | 市场数 | 赢家腿股数占比(理想 50%) |
|---|---|---|
| 最配平 1/3 | 54,708 | **53.69%** |
| 中间 1/3 | 99,805 | 73.39% |
| 最不配平 1/3 | 7,493 | 80.90% |

⇒ 分组**真的分开了**有偏与无偏,对比度成立。

## 🔴 主判决

| | |
|---|---|
| 两臂都合格的钱包 | 38,341 |
| **前 10% 名单重合率** | **75.0%** |
| **判决** | **🟡 部分污染**(红线:≥80% 绿 / <60% 红) |

**辅助(不参与判决,但操作上更要紧)**:

| 分位 | 重合率 |
|---|---|
| 前 1% | **66.8%** ← 越到头部污染越重,而我们恰恰从头部挑人 |
| 前 5% | 72.5% |

| 秩相关 | +0.8500 |

两臂的**平均** edge 几乎相同(−2.9154pp vs −2.9145pp)
⇒ 偏移**不改变整体水平,但会重排头部名次**。

## ⭐机制已精确定位

买入总股数 2,782,810,862,其中落在最终赢家腿上 **51.385%**(对称应为 50%)。
多出的 1.385pp 完整解释了那 +1.14% 的账面盈利。

| 3 | 54.47% | | 8 | 91.81% |
| 4 | 55.33% | | 9 | 91.77% |

⇒ **即使最配平的一档也是 53.5%,不存在无偏子集。** 偏移有地板,不是能靠筛样本消掉的。
第 7~10 档(只采到一条腿)是极端区,占约 6.6% 的笔数,可以剔除以降低但**不能消除**偏移。

⚠️ 数据质量小瑕疵:第 1 档 `leg_imb` 出现 −1.4e16(分母 n0+n1 近零导致),
影响极少数市场,不改变结论,但正式脚本里需加分母下限。
