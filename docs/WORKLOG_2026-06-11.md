### B3：信号链根本性故障——3层叠加错误 🔴（已修复）

这是本次最核心的修复，信号链从数据源到阈值全部失效：

#### 故障层 1：数据源用错

`identify_smart_money()` 查的是 `whales` 表，但该表的 `total_pnl` 字段对大多数鲸鱼等于 `-total_volume`（记录的是资金流出，不是真实盈亏）。

**修复**：改为查 `leaderboard_whales` 表（Polymarket 官方排行榜真实历史 PnL），并 INNER JOIN `changes` 表确保只跟踪本地有活动记录的鲸鱼。

#### 故障层 2：胜率硬编码假值

```python
# 原代码
win_rate = 0.6 if total_pnl > 0 else 0.4  # 纯猜
```

**修复**：改为真实收益率 `return_rate = pnl / volume`（如 mooseborzoi：108万/193万 = 56%）。

#### 故障层 3：回溯窗口+JOIN断链+阈值过高

- `get_recent_changes()` 只看 **1小时** 内的交易（每天约37条/38个鲸鱼，大额变动概率极低）
- `changes JOIN positions` 大量 miss（positions 只存当前仓位，非历史）
- `value_change = abs(size_change) * cur_price` 用当前价格计算历史交易价值，失真
- `min_trade_size=$1000`，头部鲸鱼单笔下注 $10-$100（被全部过滤）
- confidence 满分门槛 `$50k`（实际交易 $13-$74，永远是 0.001 分）

**修复**：
- 回溯窗口 1h → **24h**
- 直接查 `changes` 表，不依赖 positions JOIN
- 使用 `change_amount` 字段（已正确记录）
- `min_trade_size` $1000 → **$10**
- confidence 满分门槛：收益率 **30%** 为满分（归一化）；交易规模 **$5k** 为满分

**验证结果**：`scan()` 现在产生真实信号
- mooseborzoi（收益率56.1%，$1.08M历史盈利）→ 置信度80.3% ✅
- 0x53757615...（收益率66.9%）→ 置信度80.1% ✅

## 三、新增功能

### 每日自动健康巡检（`scripts/auto_health_check.py`）

**动机**：所有 bug 都是4天后用户手工回来才发现，缺乏主动检测机制。

**7项检查**：

| 检查项 | 阈值 | 触发条件 |
|--------|------|----------|
| Monitor 报告新鲜度 | >7h | 严重 |
| 信号链健康 | 2天零新增 | 警告 |
| 关键日志崩溃 | 24h内 | 警告 |
| Leaderboard 同步 | >8天 | 警告 |
| CLOB 摄像头 | >70min | 严重 |
| Cron 重复条目 | 任意重复 | 警告 |
| DB 关键表行数 | 低于合理范围 | 警告 |

**防刷屏**：同一问题4h冷却；状态恢复时发"已修复"通知。

**cron**：`0 1 * * *`（UTC 01:00 = 北京 09:00）

### Claude Code 会话启动钩子（`scripts/session_start_brief.py` + `.claude/settings.json`）

**动机**：Telegram 是实时通知，但如果用户不在手机旁，下次打开 Claude Code 时仍需手工提醒。

**机制**：
1. 健康检查每次运行后写 `07-data/.pending_issues.json`
2. `.claude/settings.json` 配置 `SessionStart` 钩子
3. 每次打开 Claude Code，钩子自动读取待处理问题并注入到对话上下文
4. 全部正常时静默退出，不打扰正常会话

**效果**：打开 Claude Code 时，如有未解决问题，对话顶部自动出现问题列表，无需用户提醒。

## 六、经验教训

1. **改完要验证**：修改信号链代码后，应立即运行 `scan()` 确认产生信号，而不是提交后离开
2. **监控自己的监控**：每次新增功能，同步更新健康检查脚本的检查范围
3. **数据来源先核实**：`total_pnl` 字段看起来是盈亏，实际是资金流出——使用前必须验证字段语义
4. **阈值要对齐真实数据**：`$1000 min_trade_size` vs `实际$10-$74`——阈值脱离数据分布等于无效
