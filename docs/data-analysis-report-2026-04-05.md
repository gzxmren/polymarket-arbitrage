## 五、核心问题诊断

### 5.1 🔴 严重问题

#### 问题1: 鲸鱼命名系统失效
**症状**: 99.9% 鲸鱼使用地址作为名称（0x...）  
**影响**: 无法快速识别鲸鱼身份，影响跟踪效率  
**根因**: 
- 可能未调用命名生成 API
- 或命名服务异常

**建议修复**:
```python
# 在 sync_changes.py 中添加命名逻辑
from pathlib import Path
import random

ADJECTIVES = ["Swift", "Silent", "Mighty", "Clever", "Bold", ...]
NOUNS = ["Whale", "Shark", "Dolphin", "Orca", ...]

def generate_pseudonym(wallet):
    """生成伪名"""
    random.seed(int(wallet[2:10], 16))
    return f"{random.choice(ADJECTIVES)}-{random.choice(NOUNS)}"
```

#### 问题2: 套利检测完全停止
**症状**: 3/27 后 cross_market_arbitrage 表无新数据  
**影响**: 失去核心盈利功能  
**根因**: polymarket-monitor.timer 被禁用  

**建议修复**:
```bash
# 恢复套利检测
systemctl --user enable polymarket-monitor.timer
systemctl --user start polymarket-monitor.timer
```

### 5.2 🟡 中等问题

#### 问题3: 警报系统失效
**症状**: 88.7% 警报未读（417/470），全部类型为 "whale"  
**影响**: 可能错过重要信号  
**建议**: 
- 实现自动标记已读机制
- 添加警报优先级分类
- 清理过期警报（>30天）

#### 问题4: 集中度指标不完整
**症状**: HHI 数据缺失，仅 Top5 有数据  
**影响**: 无法完整评估鲸鱼策略集中度  
**建议**: 修复 concentration_history 计算逻辑
