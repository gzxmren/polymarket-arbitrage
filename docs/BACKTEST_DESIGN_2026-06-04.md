## 0. 为什么是这个,为什么替换现有回测

- **现有 `08-backtests/backtest_pair_cost.py` 是假回测**,必须废弃。它没有成本模型、没有持仓、没有结算,核心仅一行拍脑袋公式 `count*(1+(0.995-threshold)*100)` 统计"机会出现次数"。违反 Roadmap 铁律 2「信回测数字,不信 demo」。
- **Pair-Cost 无法历史回测**:我们从未存过历史盘口(orderbook),只有逐日中间价。它只能往后做实时盘口采集才能验,故后排。
- **跟鲸鱼数据现在就齐**,且是 Roadmap 押注最有希望的 #1 策略 → 当前杠杆最高的一步。

|---|---|---|---|
| `changes` | 29,582 | 2026-05-04 → 06-04(整月) | **信号源**:鲸鱼成交流(wallet/market/outcome/side/old_size/new_size/change_amount/timestamp/tx_hash) |
| `daily_price_snapshots` | 39,439 | 2026-05-09 → 06-03(23天) | **价格演化**:每市场逐日 Yes 价(outcome 字段恒为 'Yes') |

## 2. 已确认的关键数据事实(决定建模)

1. **鲸鱼真实入场价可反推**:`implied_px = change_amount / |new_size − old_size|`(实测得 0.73/0.996/0.4997 等干净价)。→ 我们知道鲸鱼的实际成交价,不必只靠快照代理。
2. **价格收敛到 0/1**:快照中 18,621 个 <0.02(No 胜)、2,178 个 >0.98(Yes 胜)→ 结算可观测,「持有到结算」可算。
3. **结算判定**:`end_date` 100% 有值,20,936 行 end_date 已过 → 配合终值价可判已结算。
4. **⚠️ 快照覆盖薄(头号约束)**:12,150 市场仅 1–2 天快照;≥7 天的仅约 1,318 市场。→ **前向标记可靠的只是子集**。回测须按"可标记天数"分层报告,不能假装全样本都能跟踪到结算。

## 3. 策略定义:跟精选鲸鱼

**信号**:鲸鱼在市场 M、结果 O(∈Yes/No)、时间 T 发生 BUY(可选含 SELL 作减仓/退出信号)。

**跟随者动作建模(两档,都跑、对比):**
- **乐观档**:以鲸鱼成交价 `implied_px` 入场(假设我们能拿到同价)。
- **现实档(主口径)**:以 T **之后第一个可观测日快照价**入场(现实:通过监控发现鲸鱼动作,在下一可观测价位跟进)。两者价差本身就是"信号时效成本"。

**退出 / 标记口径(多持有期并列,不预设唯一答案):**
- `+1d`、`+3d`、`+7d` 远期收益(用对应日快照价 mark)。
- `hold-to-resolution`:持有到 end_date,终值价(收敛到 0/1)结算;若样本期内未结算 → 标记为"未结算"单列,不计入已实现期望。

**仓位**:等额名义(每信号 \$X),便于横向比较;另出"按鲸鱼成交额加权"作敏感性。

---

## 4. 成本模型(Roadmap 阶段 B 核心,缺它一切是猜)

| 成本项 | 假设(默认,可调) | 说明 |
|---|---|---|
| 交易手续费 | **0%** | Polymarket 现货撮合历史上 0 手续费(maker/taker)。保留参数位以防政策变。 |
| 点差/滑点 | **现实档已隐含**(入场用次日快照价 vs 鲸鱼价的差)+ 额外 `s` bps 保守垫 | 二元市场尾部(价≈0.99)点差对收益影响极大,须显式建模。 |
| Gas | 每笔固定 `g` 美元(Polygon,~\$0.01–0.05) | 小额跟单时占比可能不可忽略。 |
| 冲击成本/容量 | 单市场单信号可吃量 ≤ 该市场流动性的 `k%`;超出按线性冲击惩罚 | **小市场吃不下量**是 Roadmap 点名的杀手。无逐笔深度 → 用 volume/liquidity 近似容量上限。 |

→ 默认参数写在配置区,回测对 `s/g/k` 做敏感性扫描,报告"成本扫描后期望是否仍为正"。

## 5. 指标(产出)

- **扣成本后期望收益**(每信号、年化化需谨慎标注样本仅 1 月)。
- **胜率**、盈亏比、收益分布直方图。
- **按持有期分层**(+1d/+3d/+7d/resolution)。
- **按"可标记天数"分层**(回应 §2.4 约束)。
- **鲸鱼 alpha 分解**:逐鲸鱼真实跟随收益 → 找出"值得跟的少数",剔除运气/噪声(出现次数门槛 + 收益持续性)。
- **容量**:在容量上限约束下,策略可承载多少资金而期望不塌。
- Sharpe / 最大回撤(标注样本短,仅参考)。
- **一句话判决**:正期望→进纸上交易;否→砍。

## 6. 诚实声明(写进报告头部,不藏)

1. **样本仅约 1 个月**,只能测毛效应,统计稳健性弱;正期望也需更多数据复核。
2. **逐日粒度**,非逐笔/盘口;入场价是近似,日内填单未知。
3. **多结果市场被排除**(占鲸鱼活动相当比例),结论只对二元 Yes/No 成立。
4. **快照覆盖薄**,多数市场跟踪不到结算 → 远期/结算口径样本远小于入场样本。
5. **幸存者/选择偏差**:`changes` 来自被监控的鲸鱼名单,非全市场随机样本。
6. **结算用终值价近似**,非链上 resolution 事件;未结算市场不计入已实现。

## 9. 首跑结果与判决(2026-06-04)

**基线(无差别跟全部鲸鱼,base 成本档,realistic 入场,resolution 持有):🔴 不赚钱。**
- 扣成本净均值 **−2.29%**,胜率 **19.5%**,中位 −0.50%(过半交易亏)。
- 均值靠极少数**真实**长尾暴击硬撑(最高 +4034% = 0.023 买 No 结算到 0.955,真实非 bug);
  去掉 top1% → **−8.45%**。排除 longshot(入场价<0.10)更差(−4.85%)。
- `+1d` 的 +1.97% 是短持有期 + 暴击造成的假象,持有到结算即现原形。

**样本外验证(`run_whale_oos.py`,A 部分):🔴 证伪——"精选鲸鱼"是过拟合,不是真 edge。**
- 方法:按 cutoff 切 train/test,在 train 选"训练赢家",在 test 只跟他们,并检验 train↔test 持续性。
- 6 种配置(cutoff ∈ {05-16,05-19,05-21} × min-train-trades ∈ {3,5})**全部**:训练赢家在 test 段
  跑输基线 **−1.20 ~ −8.94 个百分点**;持续性 Pearson r ∈ [−0.30, +0.12],约等于 0 或负。
- **越严格选拔(min-trades 5)→ OOS 越差、相关越负** = 过拟合噪声的教科书特征。
- 结论:用同月数据挑出的"赢家鲸鱼"在样本外没有优势,跟随它们 = 跟随随机。

## 10. 自评(review,2026-06-04)

**需求**:锚定决策门(M2/M3/M4)而非堆功能,方向正确;但数据天花板(1 月/逐日)决定任何答案都只能是
"弱证据"——这点已诚实贯穿,未夸大。

**设计**:engine/strategy 解耦、成本参数化+敏感性扫描、多持有期+分层、OOS 用持续性相关作硬检验——
是这次的强项。已知局限(写入报告):
- `resolution` 口径混了"真结算"与"末次观测"(有 `resolved_only` 分离,但头条数仍混)。
- 滑点乘性建模**低估尾部**(0.99 附近书薄、真实滑点更大);capacity 的 total_deployable 求和忽略资金重叠,仅粗代理。
- 只建模买入持有,**未建模跟随鲸鱼卖出/退出**。
- 入场用"信号后首个快照",在稀疏快照下跟随滞后可达数日且不定,未归一化。

**开发**:纯标准库、只读连库、复用 config 路径、编译干净、跑通 + 6 路敏感性 + 离群诊断 + 重复行核查。
**头号缺口:金融计算引擎零单元测试**(项目有 `10-tests/` + CI,本次未补)——产出会影响资金判断的数字,
应补测试。次要:changes 有 ~1% 重复行(61/6080,immaterial,未去重);`--test` 为占位空操作。
