### 修改 sync_changes.py 实时同步 API 用户名
**时间**: 12:47 - 12:50
**执行内容**:
- 修改 `save_changes_to_db()` 函数
- 添加保存 API 返回的 pseudonym 逻辑
- 仅覆盖地址格式的名称，保留已有有效名称

**修改代码**:
```python
# 新增: 保存 API 返回的用户名
api_pseudonym = trade.get('pseudonym')
if wallet != 'unknown' and api_pseudonym and not api_pseudonym.startswith('0x'):
    cursor.execute('''
        INSERT INTO whales (wallet, pseudonym, last_updated)
        VALUES (?, ?, ?)
        ON CONFLICT(wallet) DO UPDATE SET
            pseudonym = CASE
                WHEN whales.pseudonym IS NULL 
                  OR whales.pseudonym = ''
                  OR whales.pseudonym LIKE '0x%' THEN ?
                ELSE whales.pseudonym
            END,
            last_updated = excluded.last_updated
    ''', (wallet, api_pseudonym, datetime.now().isoformat(), api_pseudonym))
```

**执行结果**:
```
获取 200 条交易记录
保存 29 条变动记录
更新 27 个鲸鱼名称  ← API 用户名同步成功！
```

**效果**:
- ✅ 每次同步变动时，自动获取 API 用户名
- ✅ 27 个鲸鱼获得真实用户名（如 Alive-Supermarket, Secret-Brooch）
- ✅ 无需 Cron 任务，实时更新

**结论**: 不再需要 Cron 任务，API 实时同步已实现！
